## 🖋구현할 기능 목록

1. 컴퓨터가 1에서 9까지 서로 다른 임의의 3자리 수를 생성한다.
2. 사용자로부터 3자리 수를 입력받는다.

- 입력값이 3자리 수가 아니거나 숫자가 아닐 경우 예외 처리한다.

3. 입력된 수와 컴퓨터가 생성한 수를 비교하여 볼, 스트라이크, 낫싱을 계산한다.

- 같은 자리에 같은 수가 있으면 스트라이크
- 다른 자리에 같은 수가 있으면 볼
- 같은 수가 전혀 없으면 낫싱

4. 비교 결과를 출력한다.
5. 3스트라이크인 경우 게임 종료를 알리고, 재시작 여부를 입력받는다.

- 1을 입력하면 게임 재시작
- 2를 입력하면 게임 종료

6. 사용자의 입력값이 올바르지 않은 경우 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.
