      1. takeUserInput() - 입력을 검사하는 기능
      2. userInputResult() -  볼,스트라이트. 낫싱 계산 기능
   3. calculate() 완성
      1. 낫싱, 3스트라이크 처리
2. Application 클래스 개임시작기능 - gameStart()
   1. 3 스트라이크 이후 - exitOrRestart()
   2. gameStart() 완성 
      1. 게임 다시시작 or 종료 결정 


    



### 요구사항
1. 1부터 9까지 서로 다른 수로 이루어진 3자리의 수를 맞추는 게임
2. 규칙 - 425 -> 123 제시 1스트라이크, 456 제시 1볼 1스트라이크, 789제시 : 낫싱
  1. 같은 수가 같은 자리에 있으면 스트라이크,
  2. 다른 자리에 있으면 볼, 같은 수가 전혀 없으면 포볼 또는 낫싱이란 힌트 상대방(컴퓨터)의 수를 맞추면 승리한다
3. 상대방의 역할을 컴퓨터가 한다(425), 입력은 사용자가 입력에 대한 결과 출력은 컴퓨터가
4. 게임을 종료한 후 게임을 다시 시작하거나 완전히 종료할 수 있다 -> 종료된 후 다시할 수 있거나 완전히 종료 할 수 있어야한다
5. 사용자가 잘못된 값을 입력할 경우 에러 발생 시킨다
6. JDK에서 기본 제공하는 Random, Scanner API 대신 다른거 사용
7. 그리고 테스트 해보세요~
8. 커밋 단위는 정리한 기능 목록 단위로 추가한다

# 메서드 흐름
1. 계산하라 (숫자) - calculate
   1. 컴퓨터 랜덤한 숫자 생성 
      1. 서로 다른 숫자 여야 한다 => contains 체크해야되서Set 사용
   2. 볼, 스타이크, 낫싱 계산후 수행 결과 반환
        1. 입력을 검사하는 기능
           1. 잘못된 값을 입력할 경우 에러를 발생 시킨다
        2. 볼,스트라이트. 낫싱 계산 기능 
           1. userInput과 ComputerInput을 서로 비교해서 문자 하나씩 반환한다 
           2. 같은 자리에 포함하면 스트라이크
           3. 다른자리에 있으면 볼
           4. 아예 아무것도 없으면 낫싱
           5. Map 사용 볼, 스트라이크 순으로 반환한다
   3. 계산하라 메세지 완성
      1. 낫싱, 3스트라이크 처리
3. Application 개암사작기능 - gameStart()
   1. 입력처리
   2. 문제 종료 처리(exitOrRestart) - 게임을 새로 시작하려면 1, 종료하려면 2를 입력하세요.
      1. 입력 에러 발생시 -> 어플리케이션 전체 종료 : 게임 종료랑 같은..건가??
      2. 3스트라이크 발생시 - 1 받으면 다시 시작한다
